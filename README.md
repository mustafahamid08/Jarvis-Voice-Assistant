🎙️ Jarvis Voice Assistant

A Python-based voice assistant that can listen to user commands and perform various tasks using voice interaction.

✨ Features

- Voice command recognition
- Text-to-speech responses
- Opens websites and applications
- Performs basic voice-based tasks
- Interactive voice assistant experience
- Responds to user commands in real time

🛠️ Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- PyAudio
- Web Browser
- OS Module

📦 Python Packages

The project uses the following Python packages:

- "SpeechRecognition"
- "pyttsx3"
- "PyAudio"

📌 Project Purpose

This project was created to practice Python concepts such as modules, functions, voice recognition, text-to-speech, user input, and automation.
